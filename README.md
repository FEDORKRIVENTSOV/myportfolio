# devcase — сайт-портфолио на Django

Портфолио с анимированными карточками проектов, фильтром «Разработка / Дизайн»,
блоками кода с подсветкой языка и мини-фактами про каждый проект. Всё содержимое
редактируется через админку Django — в код лезть не обязательно.

---

## 1. Быстрый старт в PyCharm

1. **Открой папку проекта** (`File → Open…` → выбери эту папку целиком —
   ту, где лежит `manage.py`).

2. **Создай виртуальное окружение**, если PyCharm не предложит это сам:
   `File → Settings → Project → Python Interpreter → Add Interpreter → Add Local Interpreter → Virtualenv Environment`.

3. **Открой встроенный терминал** (`Alt+F12` / внизу окна) и установи зависимости:

   ```bash
   pip install -r requirements.txt
   ```

4. **Примени миграции** (создаст файл `db.sqlite3` со всеми таблицами):

   ```bash
   python manage.py migrate
   ```

5. **Создай администратора**, под которым будешь заходить в админку:

   ```bash
   python manage.py createsuperuser
   ```

6. *(Необязательно, но приятно)* **Наполни сайт демо-данными**, чтобы сразу
   увидеть, как всё выглядит:

   ```bash
   python manage.py seed_demo
   ```

7. **Запусти сервер**:

   ```bash
   python manage.py runserver
   ```

   Открой в браузере:
   - `http://127.0.0.1:8000/` — сам сайт
   - `http://127.0.0.1:8000/admin/` — админка

В PyCharm всё то же самое можно делать без терминала: у `manage.py` есть
готовая конфигурация запуска Django-сервера (PyCharm предложит её сам, когда
откроешь проект как Django-проект — `Settings → Languages & Frameworks → Django`,
укажи `manage.py` и `config/settings.py`).

## 2. Как настроить сайт «под себя» — без единой строчки кода

Всё в `http://127.0.0.1:8000/admin/`.

### Раздел «Настройки сайта»
Одна запись на весь сайт:
- имя, роль/профессия, текст хиро-блока, текст «обо мне», аватар;
- почта, GitHub, Telegram, LinkedIn, произвольная доп. ссылка (например, Behance);
- файл резюме (PDF) — кнопка «Скачать резюме» появится на сайте автоматически;
- три забавные цифры для полоски статистики над карточками;
- секретное сообщение пасхалки (см. ниже).

### Раздел «Проекты»
Для каждого проекта:
- название, слаг (ссылка), категория **Разработка** или **Дизайн**;
- короткое и полное описание, обложка;
- теги/технологии (создаются на лету через `+` рядом с полем);
- ссылки на GitHub и демо, год, «избранный проект» (звёздочка), порядок вывода;
- **галерея** — сколько угодно доп. картинок прямо на странице редактирования проекта;
- **куски кода** — заголовок, язык, сам код — выводятся блоками с кнопкой «Копировать»;
- **мини-приколюхи** — короткие факты с эмодзи в сайдбаре страницы проекта.

Всё это — *инлайн-формы* прямо на странице проекта, добавлять новые блоки
можно кнопкой «Добавить ещё» — ничего в коде создавать не нужно.

### Пасхалка
На любой странице набери классический код Конами:
`↑ ↑ ↓ ↓ ← → ← → B A` — выскочит секретный тост с конфетти. Текст тоста
меняется в «Настройках сайта».

## 3. Структура проекта

```
devcase/
├── manage.py
├── requirements.txt
├── config/                  # настройки Django-проекта
│   ├── settings.py
│   └── urls.py
├── portfolio/                # основное приложение
│   ├── models.py             # SiteConfig, Project, Tag, ProjectImage, CodeSnippet, FunFact
│   ├── admin.py               # вся логика админки
│   ├── views.py / urls.py
│   ├── templates/portfolio/  # HTML-шаблоны
│   ├── static/portfolio/     # css/style.css, js/main.js
│   └── management/commands/seed_demo.py
└── media/                     # сюда сохраняются загруженные картинки/резюме
```

## 4. Как доделывать дальше

- **Поменять палитру/шрифты сайта** — открой
  `portfolio/static/portfolio/css/style.css`, самый первый блок `:root { ... }`.
  Там все цвета и шрифты собраны в CSS-переменные — меняешь их одним местом,
  и перекрашивается весь сайт.
- **Добавить новое поле проекту** (например, «роль в команде») — добавь поле
  в `portfolio/models.py`, вызови в терминале
  `python manage.py makemigrations && python manage.py migrate`,
  добавь поле в `fieldsets` в `portfolio/admin.py` и выведи его в шаблоне
  `portfolio/templates/portfolio/project_detail.html`.
- **Добавить новую страницу** — новый `View` в `views.py`, путь в `urls.py`,
  шаблон в `templates/portfolio/`, ссылка в `base.html`.
- **Подсветка синтаксиса покрасивее** — сейчас код выводится моноширинным
  шрифтом без цветной подсветки токенов. При желании можно подключить
  Prism.js или Highlight.js через CDN в `base.html`.

## 5. Перед тем как выложить сайт в открытый доступ

1. В `config/settings.py` поставь `DEBUG = False` (или переменную окружения
   `DJANGO_DEBUG=False`).
2. Задай `DJANGO_ALLOWED_HOSTS` — домен, на котором будет жить сайт.
3. Вынеси `SECRET_KEY` в переменную окружения `DJANGO_SECRET_KEY`.
4. Выполни `python manage.py collectstatic` и настрой отдачу статики/медиа
   на своём хостинге (Render, Railway, PythonAnywhere, VPS — на выбор).

Удачи с трудоустройством — начинка сайта теперь полностью в твоих руках. 🚀
