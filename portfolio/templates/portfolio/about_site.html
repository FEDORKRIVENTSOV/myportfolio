Кстати, этот сайт — тоже пет-проект

Да, портфолио, которое ты сейчас листаешь, само является одним из пет-проектов. Мета настолько, насколько это вообще возможно.

Стек

  • Backend — Django 5
  • База данных — SQLite (легко заменить на PostgreSQL)
  • Фронтенд — чистые HTML / CSS / JS, без фреймворков
  • Все тексты, картинки и проекты редактируются через админку

Что настраивается без кода

  • Имя, роль, текст хиро-блока и раздел «обо мне»
  • Ссылки на соцсети и резюме
  • Любое количество проектов с тегами, галереей и кодом
  • Три забавные цифры в статистике
  • Секретное сообщение пасхалки

Хочешь так же? Исходники лежат рядом — заходи в portfolio/models.py, если понадобится что-то докрутить.
